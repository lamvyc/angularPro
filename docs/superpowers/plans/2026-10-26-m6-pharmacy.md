# M6 药房库存 Implementation Plan

**Goal:** 药品目录、批次入库、FEFO 发药、按原批次退药、库存流水与对账，保证可用量非负。

**Architecture:** 发药条件扣减 `stock_qty/reserved_qty`；处方状态条件更新与预占状态联动；退药按原预占批次回补，过期批次隔离；重复发药幂等，重复退药使用 Idempotency-Key。

**Tech Stack:** Spring Boot 4.1 / MyBatis / MySQL / Angular 22 Signals。

**Spec:** `docs/requirements.md` M6、`docs/business-flows.md` 6、`docs/database-design.md` 4.8。

## 验收

- 药品编码唯一；停用不影响历史处方。
- 过期批次入库 422；有效批次写 IN 流水。
- 发药扣实库存与预占；重复发药不重复扣减。
- 退药不超过已发；同幂等键只回补一次；过期批次转 QUARANTINE。
- 汇总/流水可对账，任意时刻可用量非负。
- 前端药房可发药/退药；库存页可维护目录、入库、查看批次/流水。
- 后端全量、前端 lint/test/build 通过。
