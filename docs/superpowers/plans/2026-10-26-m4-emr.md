# M4 电子病历 Implementation Plan

**Goal:** 结构化模板、模板版本、动态渲染、条件校验、签署不可变、修订与版本历史、模板管理。

**Architecture:** 模板版本 JSON Schema；病历固定 `template_version_id`；后端统一校验；签署写规范化 SHA-256 与不可变快照；修订生成新版本并置旧版本 `SUPERSEDED`。

**Tech Stack:** Spring Boot 4.1 / MyBatis / MySQL JSON / Angular 22 Signals。

**Spec:** `docs/requirements.md` M4、`docs/business-flows.md` 4、`docs/database-design.md` 4.6。

## 验收

- 模板发布后不可原地改；新版本只影响新病历。
- 动态字段/条件显示/条件必填；后端 422 + fieldErrors。
- 签署后草稿接口 409；结束就诊要求 SIGNED/AMENDED。
- 修订生成新版本，旧版本 SUPERSEDED，记录 AMENDED，审计含版本与哈希。
- 前端可签署、修订、查看版本并对比、打印；管理员可建模板/发版/归档。
- 后端全量、前端 lint/test/build 通过。

## Tasks

1. V6 模板/版本/签署字段/快照 + 内置模板；V7 管理员模板读权限。
